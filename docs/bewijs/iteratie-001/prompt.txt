Bouw met Lovable een complete, werkende Nederlandstalige mobile-first schoolplanner voor Freek. Projectnaam: Schoolplanner. De gebruiker heeft expliciet GitHub Pages op https://github.com/Freekvrijn/schoolplanner gevraagd; alle code gaat later op main. Ik exporteer je bestanden via de API. Gebruik React + TypeScript + Vite, Tailwind en lucide-react, GEEN serverframework, geen Supabase of account nodig. Het resultaat moet volledig statisch deploybaar zijn onder /schoolplanner/ (Vite base /schoolplanner/, hash routing indien routes nodig zijn). Bouw daadwerkelijk de app nu, geen plan-only.

Gebruikersbriefing letterlijk: "Oke maak een website MET LOVABLE waar ik al mijn schoolzaken kan regelen ik wil dat hij mijn lessen ophaalt vanuit mijn agenda https://avans.one/api/webcal?value=28026KM12AIA&c=g en dan per les aantekeningen kan aanmaken en bij aankomende lessen kan aangeven wat ik voor die les gedaan moet hebben. Mobile first moet het zijn zet alles live in deze repo https://github.com/Freekvrijn/schoolplanner mag alles op main zetten is github pages"

ONTWERP:
Maak een heel verzorgde rustige studieomgeving, "Schoolplanner", met donker inktblauw, warme offwhite achtergrond, wit, een helder limegroen accent, subtiele paarse en blauwe vakaccenten. Gebruik sterke typografie (bijv. DM Sans + compacte monospace labels), royale witruimte, fijne randen, ingetogen schaduwen. Geen algemene marketinglandingpage maar een functionele persoonlijke planner. Een compact logo met een kalender/boek-icoon. Desktop sidebar (Vandaag, Agenda, Taken, Aantekeningen, Instellingen), hoofdgebied met begroeting "Alles klaar voor je volgende les.", datum, weeknavigatie en komende lessen, kleine voortgangssamenvatting. Mobile op 375px: bottom navigation, plakkerige compacte header, simpele dag/weekselectie, genoeg ruimte voor duimbediening, minimaal 44px controls, geen horizontale overflow. Desktop overzichtelijk in twee kolommen met "Eerstvolgende les" en "Nog te doen". Nederlandse datums en 24-uurs tijden. Geen stockfoto's nodig.

FUNCTIONEEL MVP:
- Echte lessen uit Avans ICS: https://avans.one/api/webcal?value=28026KM12AIA&c=g
- Browser-CORS ontbreekt op die URL. Fetch deze URL NIET rechtstreeks vanuit de browser en gebruik GEEN publieke CORS proxy.
- Maak scripts/sync-calendar.mjs die deze ICS server-side met Node ophaalt, response en VCALENDAR valideert, parseert met een geschikte kleine dependency (bijv node-ical of ical.js), en public/rooster.json schrijft. Neem stabiele originele UID als les-ID, title, start/end ISO met correcte Europe/Amsterdam tijdzone (de echte feed gebruikt floating DTSTART:20261113T093000 plus X-WR-TIMEZONE:Europe/Amsterdam), location, description en eventueel docenten uit description op. Dedupliceer UID, sorteer, sla geannuleerde lessen over. JSON envelope: { updatedAt, source, events }. Zet TZ=Europe/Amsterdam voor sync als nodig; voorkom 1 uur verschuiving. Voeg npm script sync:calendar toe.
- De browser haalt uitsluitend `${import.meta.env.BASE_URL}rooster.json` op, toont laatste sync, laadstatus, lege staat en begrijpelijke fouten, en houdt de vorige succesvolle agenda bij als offline cache. Reload-knop haalt dit gepubliceerde bestand opnieuw op; zeg eerlijk dat GitHub de bron periodiek vernieuwt.
- Maak geen verzonnen lessen of nepstatistieken als eindresultaat. Als sync hier niet werkt toon eerlijke lege/foutstatus, ik voer de sync lokaal uit. Bij eerste build kan een geldig leeg JSON bestand aanwezig zijn; probeer de echte sync nu als netwerktoegang mogelijk is.
- Agenda: dag/week navigatie en komende lessen gegroepeerd per dag; vandaag en week terug/vooruit controls; filter/zoek op vak; toon lokaal, begin/eindtijd en vak duidelijk. Vandaag-scherm toont vandaag plus eerstvolgende les; als vandaag leeg is, toon komende echte les. Historische lessen blijven bereikbaar.
- Klik op een les: detail sheet/dialog met titel, datum, tijd, lokaal, bronbeschrijving; tab/sectie "Voorbereiding" en "Aantekeningen".
- Per les meerdere voorbereidingstaken toevoegen, afvinken, bewerken en verwijderen. Lesdatum is de deadline, voeg optioneel eerdere deadline toe als eenvoudig. Takenoverzicht: open/afgerond, volgorde op lesdatum, achterstallig onderscheiden.
- Per les eigen aantekeningen typen, automatisch opslaan met zichtbare opslagstatus; aantekeningenoverzicht met zoekfunctie. Bewaar op stabiele UID zodat rooster opnieuw laden de inhoud niet weggooit. Houd data van verdwenen lessen ook in opslag en bereikbaar in Taken/Aantekeningen (metadata bewaren).
- Persistent localStorage met versie/schema, foutafhandeling bij ongeldige of volle opslag. Geen claim dat gegevens tussen apparaten synchroniseren. Heldere kleine uitleg bij instellingen: "Je aantekeningen en taken blijven in deze browser."
- JSON backup downloaden en backup importeren met validatie en expliciete bevestiging voordat bestaande data wordt vervangen; ongeldige import mag huidige data nooit wissen.
- Goed werkende schermen/knoppen/empty states, toegankelijke labels, keyboard support, Escape sluit sheet, focus netjes. Mobile toetsenbord en bottom nav mogen opslaan/velden niet bedekken.
- Geen auth, AI-chat, betaling of database toevoegen.

GITHUB PAGES:
